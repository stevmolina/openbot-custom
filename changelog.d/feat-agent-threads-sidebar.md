### Changed

- The sidebar now lists threads by what they need. "Needs you" shows every chat or side thread of any agent that waits for an approval, an answer or a browser takeover. "Working" shows every thread with a running turn. "Agents" lists each agent once, with its role, and marks an agent with a new reply.
- Agents with the same name and face show as copies of one agent: "Agents" lists the first one, and the threads of each copy show its role title.
- The chat header has one row of tabs for all agents, as in a browser. Each tab shows the agent's face with the thread's state, and opening a thread from the sidebar adds its tab at the end.
- Folders no longer show in the sidebar. They are kept, and the order of the agents follows them.
