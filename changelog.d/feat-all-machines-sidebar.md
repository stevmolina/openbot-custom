### Added

- Add an "All machines" view to the sidebar. Choose it at the top of the server menu to see the agents of every server at once, one folder per server. Click an agent to open its chat on its own server; the app switches for you. New asks which server gets the agent. A server that is offline or asleep shows its state and a Retry button, and the other servers stay. Mark all read reads the chats of every server.

### Changed

- A server with no logo now shows a black and white mark with the first letter of its name, or a laptop for the server on this computer, in place of the gradient ball.
