### Changed

- When you ask an agent to add, connect or use an MCP server that is saved, such as Composio, the agent
  now tests the server and shows the Sign in card in the chat. Before, it could answer that it had no
  tool to connect the server. After the sign-in, a Composio agent gives you the link to connect the
  app that you need.

### Fixed

- An agent now finds a Composio server that an earlier version of the Composio app saved. Before, it
  asked you to connect Composio again from Marketplace instead of signing in to the saved server.
