### Changed

- On a phone, the web client shows the chat list as one scrolling list: an open folder now shows all its agents, and folder headings are larger.
- The phone tab bar floats over the list and holds Chats, Tasks, Workflows and Settings. Tasks and Workflows show only when the server has them.
- Tap the server name at the top of the list to switch servers. A search field sits under it, and the other pages (Usage, Schedule, Marketplace, Help) are in the "…" menu beside New.
- The Discord card, the usage rings and the bottom button bar no longer show on a phone.
- In a chat on a phone, the icons under each message are hidden (a long press opens the same actions), the model shows as its logo, and the message box floats.
