### Added

- Select Create an Artifact from a Claude chat's + menu to use Artifact tools for one message. Remove the chip to cancel. The choice clears on Send and stays with queued work, edits, retries and continuations. Desktop, joined desktop, web and mobile support the action. Existing side threads support it on desktop and web.
- This option can publish content to the host's claude.ai account. It does not enable the account's connectors. The global Use claude.ai tools setting still enables both.
- Joined servers must update to this version before the action is available.
