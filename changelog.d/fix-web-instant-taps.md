### Fixed

- Switches now move as soon as you tap them. Before, a switch waited for the server to answer before it moved, which felt slow on the web app and on an iPad. If the save fails, the switch goes back and shows the error.
- Turning a skill on or off for an agent no longer dims the switch, and the skill list reloads in the background.
- In Server settings, one pending change no longer dims the other settings or drops your taps on them.
- On the web app, a chat starts to load when you press its name in the sidebar, and more recent chats load early, so chats open faster.
