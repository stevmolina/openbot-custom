### Added

- Agents can use Agent Computer cloud computers with built-in tools: start or resume a computer, run commands, take screenshots, get or publish files, pause, list and delete. Deleting always asks you first.
- Server Settings has a new Cloud computers section, where an owner or admin connects, tests and disconnects the server's Agent Computer API key. The Machines page shows each server's cloud computers with a Live view button. A joined server must also run this version.

### Changed

- Coding jobs (`run_coding_task`) use the built-in Agent Computer connection. They no longer need Composio or an MCP server.
